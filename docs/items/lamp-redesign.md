# 등불 재설계 — 원형 허리케인 랜턴

브랜치 `feature/lamp-redesign`. 레퍼런스 1·2의 연료통, 둥근 유리와 측면 프레임에 3의 청동 돔·돌기, 4의 덩굴·잎 장식을 조합했다. 조립 높이는 약 1.027, 바닥은 0이다. 앞면은 +Z다. 기존 등불과 파일 이름을 구별하기 위해 이번 모델은 `Models/lamp_v2_*`에 둔다. 게임 연결은 별도 단계다.

## 1. 프로파일

각 파일의 POINTS는 (반지름, 높이) 좌표다. 곡선 보간은 끄고 입력 점을 직선으로 잇는다. 분할 각도는 회전 범위를 분할 수로 나눈 값이다.

## 2. 조립

변환 순서는 크기 → 회전 → 위치다. 아래 좌우·앞뒤 반복은 이 변환 뒤에 원점 기준 Y축 회전을 적용한다. 크기와 회전이 비어 있는 기본 부품에는 단위 크기와 0°를 쓴다.

| 부품 | 위치 (x, y, z) | 회전·크기·반복 | 미리보기 색 |
|---|---|---|---|
| 연료통 / 유리 / 돔 / 버너 / 불꽃 | (0, 0, 0) | 기본 변환 | 각 `#70482A` / `#F0BC5D` (불투명도 19%) / `#7A502E` / `#98642F` / `#FF8529` (불투명도 36%) |
| 직선 지지대 | (0.210, 0.224, 0) | Y 0°, 180°에 반복 | `#794F2D` |
| 아래·위 굽은 관 | (0.146, 0.224, 0), (0.146, 0.648, 0) | 각각 X −90°, +90° 후 Y 0°, 180°에 반복 | `#794F2D` |
| 손잡이 아래 굴곡 | (−0.010000, 0.660000, 0) | X +90° 후 Y 0°, 180°에 반복 | `#9E6A41` |
| 손잡이 위 굴곡 | (0.403465, 0.810489, 0) | X −90° → Z +200° 후 Y 0°, 180°에 반복 | `#9E6A41` |
| 손잡이 아치 | (0, 0.810489, 0) | 로컬 크기 (1, 1, 0.210/0.183465) 후 X +90° | `#9E6A41` |
| 돌기 | (0.151, 0.709, 0) | Y 45°, 135°, 225°, 315°에 반복 | `#D6A558` |
| 조절 손잡이 | (0, 0.177, 0.172) | X +53° | `#D6A558` |
| 통풍구 무늬 | (0, 0.768, 0.0825) | leaf 재사용, 크기 (0.57, 0.67, 0.19), Y 0°부터 30° 간격으로 12회 | `#231811` |

유리 장식은 앞면에 아래처럼 배치하고 전체를 Y 180° 회전해 뒤에도 반복한다.

- 곡선 호는 x = ±0.039이고, 위쪽 (y, z) = (0.619, 0.120), 아래쪽 = (0.334, 0.111)이다. X +90° 후 위쪽 Z +35°, 아래쪽 Z −60°를 적용한다. x가 음수인 경우 Z 각도에 180°를 더한다.
- 줄기는 x = ±0.061에서 (y, z) 네 구간을 잇는다. 점은 (0.348, 0.115), (0.405, 0.138), (0.455, 0.143), (0.550, 0.129), (0.602, 0.115)이다. 각 구간의 첫 점에 tube를 놓고, x·z 크기 0.16, y 크기 구간길이/0.424, X 회전 atan2(Δz, Δy)를 적용한다. 호는 `#9D673A`, 연결줄은 짙은 청동 `#3E2B22`다.
- 잎은 x = ±0.061, (y, z) = (0.390, 0.130) 및 (0.527, 0.135)이다. 크기는 (1, 1, 0.4)이고 x가 양수면 Z −33°, 음수면 Z +33°다. 색은 `#AE7441`이다.

기본 강조색은 두 가지다. 짙은 청동 `#3E2B22`는 돔의 통풍구 띠(y = 0.754~0.786)와 연료통 하단 띠(y = 0.080~0.104)에 쓴다. 밝은 황동 `#D6A558`은 돌기, 조절 손잡이, 버너 윗테두리(y = 0.324~0.338)에 쓴다. 높이 범위는 각 삼각형의 중심 높이로 구분한다. 이 색은 조립할 때 적용한다.

불꽃 세 부품은 모두 원점에 조립한다. 금빛 안쪽 불꽃 `#FFD15C`는 불투명도 66%, 아이보리 심부 `#FFF1B3`는 불투명도 100%를 쓴다. 미리보기에서는 심부 → 금빛 불꽃 → 주황색 외피 → 유리 순서로 합성한다.

금속 미리보기는 세 색을 더 사용한다. 회갈색 `#555A55`는 돔의 y = 0.677~0.699, 0.786~0.792 구간과 관의 어두운 면에, 적갈색 `#965938`은 연료통의 y = 0.013~0.025, 0.103~0.111 및 돔의 y = 0.698~0.709 테두리에 적용한다. 옅은 금빛 `#EED3A3`은 청동 및 황동 표면의 방향성 반사광으로 섞는다.

손잡이는 한쪽에 동일한 20° 관을 두 번 이어 총 0.026535만큼 안으로 들어간다. 연결부의 13개 단면 정점이 상대 부품과 일치하는지 검사했다.

## 3. 확인

- [x] 임시 스크립트로 15개 프로파일을 회전해 정점 수, 인덱스 범위, 퇴화 삼각형 유무를 검사했다.
- [x] 정면, 우측, 후면 사선, 상단 사선에서 조립을 확인했다. 직선 관과 굽은 관의 접점 높이를 맞추고, 줄기를 분절해 유리 곡면에 가깝게 배치했다.
- [x] 모델러에서 15개 프로파일을 열어 같은 이름으로 DAT 저장.
- [x] 저장된 DAT 15개의 정점과 법선을 독립 계산 결과와 정밀도 범위 내에서 대조했고, 삼각형 인덱스는 정확히 일치했다.

부분 회전 관은 양 끝이 열린 메시다. 지지대의 노출된 관 끝은 이웃 부품의 접점 또는 연료통·돔 안으로 들어간다. 유리 덩굴은 개별 호와 잎을 반복했고, 통풍구는 어두운 장식 메시로 표현했다. 재질과 부품 배치는 조립 시 적용한다.
