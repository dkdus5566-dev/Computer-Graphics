# 아리아드네의 실타래

| 항목 | 내용 |
|---|---|
| 담당 | 실타래 |
| 브랜치 | `feature/ariadne-thread` |
| 레퍼런스 | 사용자가 제공한 여덟 장의 보라색 실타래 이미지. 황동 실패, 기울어진 축, 금사가 든 실, 바닥에 풀린 실끝을 기준으로 삼았다. |
| 게임 속 역할 | 탈출에 쓰이는 수집 아이템 |

## 1. 디자인

황동 밑판과 윗판 사이로 짙은 보라색 실이 27개의 둥근 골을 이룬다. 바깥에는 금사를 덧댄 밝은 보라색 실 한 가닥을 일곱 바퀴 감는다. 한쪽에서 풀린 실은 바닥에서 두 번 방향을 바꾼다. 윗판의 월계수 잎과 동심원 인장, 밑판 정면의 인장이 앞쪽을 표시한다. 레퍼런스의 금속 각인은 축소해도 읽히는 돌출 장식으로 단순화했다.

## 2. SOR 부품

각 링크는 모델러에 입력되는 **전체 점 좌표**를 담고 있다. 첫 열은 반지름, 둘째 열은 높이다. 모든 파일은 직선 보간을 사용한다. 작은 원형 단면의 점 순서는 위 → 바깥 → 아래 → 안 → 위다. 윗판은 구멍 안쪽 벽까지 이어진다.

| 프로파일 | 형태 | 회전 범위 / 분할 수 |
|---|---|---|
| [base](../../Models/ariadne_base.prof) | 밑판. 바닥 반지름 0.316, 가장 넓은 테 0.334 | 360° / 96 |
| [lid](../../Models/ariadne_lid.prof) | 윗판. 중앙 구멍의 최소 반지름 0.062 | 360° / 96 |
| [yarn](../../Models/ariadne_yarn.prof) | 실이 감긴 몸통. 실골 반지름 0.289~0.303, 축을 받치는 중앙 홈 | 360° / 96 |
| [spindle](../../Models/ariadne_spindle.prof) | 끝에 두 겹 테가 있는 황동 축 | 360° / 64 |
| [wrap](../../Models/ariadne_wrap.prof) | 보라색 겉실. 중심 반지름 0.302, 단면 반지름 0.0105 | 10° / 4 |
| [filament](../../Models/ariadne_filament.prof) | 겉실에 박힌 금사. 중심 반지름 0.3115, 단면 반지름 0.0027 | 10° / 4 |
| [tail](../../Models/ariadne_tail.prof) | 풀린 실. 중심 반지름 0.15, 단면 반지름 0.008 | 15° / 6 |
| [leaf](../../Models/ariadne_leaf.prof) | 양끝이 가늘어지는 장식. 잎, 테두리 빗금, 실끝 마감에 재사용 | 360° / 16 |
| [seal](../../Models/ariadne_seal.prof) | 동심원 세 줄이 솟은 인장 | 360° / 64 |

## 3. 조립

바닥은 y = 0, 정면은 +z다. 좌표는 모델 단위이며 조립 높이는 0.98325다. 아래 행렬은 열벡터에 적용한다. 색은 0~255 범위의 RGB다.

| 부품 | 위치 (x, y, z) | 회전 및 크기 | 재질 RGB |
|---|---|---|---|
| 밑판·윗판 | (0, 0, 0) | 원래 크기 | 황동 (177, 107, 47) |
| 몸통 | (0, 0, 0) | 원래 크기 | 짙은 보라 (80, 27, 111) |
| 축 | (0, 0.659, 0) | Z축 −16° | 황동 |
| 정면 인장 | (0, 0.039, 0.329) | X축 90° | 금 (231, 166, 75) |
| 윗판 인장 | (0, 0.738, 0.145) | 크기 (1.45, 0.70, 1.45) | 금 |

### 사선 겉실과 금사

두 프로파일에 같은 변환을 적용한다. 겉실 RGB는 (133, 47, 154), 금사는 (244, 174, 88)이다. 각 조각의 시작과 끝은 이웃 조각과 단면 전체가 맞닿는다.

1. 조각 번호 k는 0~251이다. δ = π/18, θ = 0.9π + kδ로 두고 수평 좌표를 Y축으로 θ만큼 돌린다.
2. t = k/252일 때 높이 함수는 H(k) = 0.055 + 0.652t + 0.055 sin(16πt) sin(πt)다.
3. u = (H(k) − 0.381)/0.302, w = (u cosδ − (H(k+1) − 0.381)/0.302)/sinδ다.
4. 원래 점 (x, y, z)의 최종 높이는 0.381 + ux + y + wz다. 이 식에 들어가는 x, z는 회전 전의 좌표다. 처음과 마지막 단면은 각각 밑판과 윗판 안에서 끝난다.

### 풀린 실

P는 조각의 시작점, T는 진행 방향, K는 곡선이 휘어지는 단위 방향이다. U = (0,1,0), R = 0.15, a = 15°로 둔다. P = (0.272, 0.308, 0.050), T = normalize(0.31, 0, 0.95)로 시작한다.

1. 각 원호의 중심은 C = P + RK다. 원호를 C로 옮기고, 로컬 X·Y·Z축을 각각 −K, (−T) × (−K), −T로 향하게 한다.
2. 다음 시작점은 C − R cos(a) K + R sin(a) T다. 다음 T와 K는 각각 cos(a) T + sin(a) K, cos(a) K − sin(a) T다. 둘 다 갱신 전 값을 사용한다.
3. K = −U에서 6조각을 내려가고, 직전의 K를 반전해 6조각을 더 잇는다. 여기서 실의 중심 높이는 0.008이다.
4. 바닥에서는 각 구간을 시작할 때 K를 새로 정한다. T × U 방향으로 8조각, −(T × U)로 4조각, T × U로 6조각을 잇는다.
5. 마지막 P에 잎 부품의 중심을 놓는다. 긴 축을 T로 향하게 하고, 단면 크기 0.025, 길이 크기 0.024를 적용하면 열린 단면이 닫힌다. 풀린 실과 마감의 색은 겉실과 같다.

### 잎과 테 장식

각도 a에서 바깥 방향은 D = (sin a, 0, cos a), 접선은 B = (cos a, 0, −sin a)다. 잎의 긴 축을 A, 표면의 바깥 방향을 V라 할 때 로컬 축은 normalize(A × V), A, normalize((A × V) × A) 순서다.

- **월계수**는 양쪽 s = ±1에 각각 12쌍이다. j = 0~11, a = s(29 + 10j)°, h = ±1로 둔다. 잎의 중심은 (0.254 + 0.009h)D + 0.738U, 긴 축은 normalize(sB + 0.67hD), V = U다. 크기는 (0.025, 0.043, 0.009), RGB는 (204, 139, 63)이다.
- **금속 테의 빗금**은 높이 0.037, 0.705에 각각 60개다. a = 6j°, j = 0~59일 때 중심은 0.328D + 높이 × U, 긴 축은 normalize(B + 0.46U), V = D다. 크기는 (0.011, 0.026, 0.010), 색은 금이다.

## 4. 게임 능력

팀 지침에는 실타래의 역할이 탈출로 정해져 있다. 이번 제작 범위는 수집 아이템의 SOR 모델이다.

## 5. 시연에서 설명할 원리

모델러는 점 (r, y)을 회전해 (r cosθ, y, −r sinθ)를 만든다. 360° 회전에서는 처음과 끝 열이 연결된다. 겉실은 10°만 돌려 열린 원호를 얻은 뒤, 각 원호의 높이를 달리해 실패 둘레를 타고 오르게 한다. 색과 기울기는 조립할 때 적용된다. 개별 프로파일을 모델러에서 열면 해당 부품의 기본 형상이 보인다.

## 6. 확인

- 저장소 밖 미리보기 프로그램에서 공용 `LoadProfile`과 `BuildSOR`로 아홉 파일을 열고 정면·오른쪽·후면·왼쪽을 렌더링했다.
- 첫 조립에서 겉실 이음새의 단면이 어긋나 변환식을 수정했다. 최종 겉실·금사의 최대 이음 오차는 0.00000004 미만이다. 풀린 실의 시작 단면은 몸통 안으로 넣었고, 바닥 원호 18개가 y = 0에 닿는다.
- 축과 윗판 구멍 사이의 최소 여유는 보수적으로 0.00365 이상이다. 풀린 실 중 밑판 높이에 있는 정점은 모두 밑판 최대 반지름 밖에 있다.
- **모델러 저장 및 검사 완료.** 사용자가 부품 9개를 모델러에서 저장했다. 저장된 메시의 정점 23,389개와 단위 법선은 대응 프로파일로 재생성한 값과 소수점 여섯 자리 저장 정밀도에서 일치했다. 삼각형 45,120개의 인덱스와 정점 순서가 모두 일치했고, 면적이 0인 삼각형은 없었다.
