## 1. 문제 해결 사례

### 사선으로 감기는 겉실의 이음새

레퍼런스에서는 금사가 섞인 보라색 실이 실패 둘레를 비스듬히 돈다. 모델러에서 단면을 Y축으로 회전시키면 한 바퀴를 돌아도 시작 높이로 되돌아온다. AI는 실과 금사를 각각 10° 원호로 만들고, 조립할 때 원호마다 양 끝의 높이를 지정했다.

첫 조립에서는 이웃 원호의 단면이 조금 어긋났다. AI가 두 원호가 공유하는 단면 전체에 같은 높이 변환이 적용되도록 식을 고쳤다. 네 방향으로 다시 조립하고 경계 정점을 비교한 결과, 겉실과 금사의 최대 이음 오차는 모델 단위 0.00000004 미만이었다. [조립식과 검증 결과](../items/ariadne-thread.md)

### 모델러에서 저장한 메시 확인

담당자가 모델러에서 부품 9개를 저장한 뒤 AI가 각 프로파일에서 메시를 다시 생성해 저장 파일과 비교했다. 정점 23,389개와 법선은 파일의 소수점 여섯 자리 정밀도에서 일치했다. 삼각형 45,120개의 인덱스와 정점 순서가 일치했고 면적이 0인 삼각형은 없었다. [겉실 프로파일](../../Models/ariadne_wrap.prof) · [저장된 겉실 메시](../../Models/ariadne_wrap.dat)

## 2. 시연용 원리 메모

| 질문 | 설명 |
|---|---|
| 단면의 점이 어떻게 3D 정점이 되나? | 반지름 r, 높이 y인 점을 Y축 둘레로 θ만큼 돌리면 좌표는 (r cosθ, y, −r sinθ)가 된다. |
| 정점 번호와 삼각형은 어떻게 정하나? | 단면에 점이 P개면 i번째 회전 열의 j번째 정점 번호는 i × P + j다. 이웃한 두 열의 대응 점을 연결해 사각형을 만들고 두 삼각형으로 나눈다. 회전축에 닿아 면적이 사라지는 삼각형은 건너뛴다. |
| 법선은 어떻게 구하나? | 삼각형의 두 변을 외적해 면 법선을 구한다. 각 정점에 이웃 면의 외적을 더한 뒤 길이를 1로 맞춘다. |
| 같은 원호를 왜 여러 번 배치하나? | 짧은 겉실 부품 하나를 반복해 일곱 바퀴를 감을 수 있다. 실과 금사에 같은 변환을 적용해 감기는 동안 두 가닥의 위치 관계를 유지한다. |
