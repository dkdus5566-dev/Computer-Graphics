| 항목 | 내용 |
|---|---|

## 1. 문제 해결 사례

### 사각 등불과 손잡이 조립

| 항목 | 내용 |
|---|---|
| 문제 | 동일한 네 면을 갖는 몸체와 세로 손잡이를 기존 SOR 모델러로 구현해야 했다. |
| AI가 한 일 | 받침·지붕·기둥·유리는 4분할, 둥근 부품은 다분할로 설계하고 공용 SOR 생성기로 메시를 만들었다. |
| 검증 방법 | 정면, 우측, 후면 사선, 상단 사선에서 조립 결과를 확인했다. |
| AI의 실수와 수정 | 초기 고리 하단이 지붕을 침범해 중심 높이를 0.962로 올렸다. 고리 하단이 지붕 위에서 고리 받침에 맞물리는지 다시 확인했다. |
| 내가 한 일 | 참고 이미지를 제시하고 사각 몸체와 원형 손잡이 구성을 선택했다. |
| 증거 | [등불 설계서](../items/lamp.md)의 부품 구성과 조립 좌표 |

### 모델러 실행 및 저장 파일 검증

| 항목 | 내용 |
|---|---|
| 문제 | Windows 앱 제어가 모델러 실행을 차단했고, 저장 후에는 각 DAT가 원본 프로파일에 대응하는지 확인해야 했다. |
| AI가 한 일 | Windows 코드 무결성 기록에서 서명 요건 차단을 확인했다. 이후 모델러를 다시 실행하고 저장 파일을 검사했다. |
| 검증 방법 | 9개 DAT를 공용 로더로 읽고 같은 프로파일에서 재생성한 결과와 비교했다. 정점·법선은 저장 정밀도 내에서 일치했고 삼각형 인덱스는 정확히 일치했다. |
| 내가 한 일 | 모델러에서 각 프로파일을 열고 같은 이름으로 DAT 9개를 저장했다. |
| 증거 | [모델 폴더](../../Models)의 `lamp_*.prof`, `lamp_*.dat` |

## 2. 원리 설명 준비

| 질문 | 설명 |
|---|---|
| 프로파일 점은 어떻게 3D 정점이 되나? | 반지름 r, 높이 y인 점을 Y축 둘레에서 θ만큼 돌리면 3D 좌표는 (r cos θ, y, −r sin θ)다. 4분할은 θ가 90°씩 변하므로 사각 단면이 생긴다. |
| 정점 번호와 삼각형은 어떻게 정하나? | 프로파일 점이 P개면 i번째 회전의 j번째 점은 i × P + j다. 인접한 두 회전 단계와 두 프로파일 점으로 사각형을 만들고 삼각형 두 개로 나눈다. 마지막 회전 단계는 첫 단계로 연결한다. |
| 법선은 어떻게 구하나? | 삼각형 두 변의 외적으로 면 법선을 구한다. 정점에 닿는 면의 외적을 합하고 단위 길이로 정규화한다. |
| 고리는 왜 X축으로 회전시키나? | Y축을 중심으로 생성하면 고리가 XZ 평면에 놓인다. X축을 중심으로 90° 돌려 수직으로 세운 뒤 받침 위로 옮긴다. |
